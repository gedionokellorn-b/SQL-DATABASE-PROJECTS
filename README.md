Hospital Management Database

1. Project Overview

The Hospital Management Database is an SQL database project designed to manage hospital operations and organize patient information, doctors, appointments, departments, and medical records.

2. Project Objectives

- Store and manage patient information.
- Manage doctor and staff records.
- Track patient appointments.
- Organize hospital departments.
- Maintain medical records.
- Manage billing and payments.

3. Database Tables

The database contains the following proposed tables:

1. Patients
2. Doctors
3. Departments
4. Appointments
5. Medical_Records
6. Payments

- SELECT
- UPDATE
- DELETE

- GROUP BY
- JOIN
- Primary Keys and Foreign Keys
- Aggregate Functions
